# Source and Copyright Policy

This public repository must not contain raw copyrighted episode transcripts, ebook text, video, audio, or scanned pages.

Allowed repository material includes source manifests, hashes, locators, factual metadata, structured derived records, original analysis, reconciliation decisions, and code.

## Locator requirements

Locators should be source-variant aware. Depending on medium they may include line ranges, chapter/section/paragraph ordinals, page references when edition-stable, timecode ranges, and a normalized local-passage fingerprint. A locator should remain useful even when a hosting site changes formatting.

## Provenance lineage

Every external source should carry a provenance family or `derived_from` chain when known. STAPI, rtrek, Memory Alpha, Memory Beta, and other downstream datasets must not be counted as independent witnesses merely because they expose separate endpoints.
