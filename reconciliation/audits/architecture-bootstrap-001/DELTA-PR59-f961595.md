## Auditor corrections to the test oracle

### AUD-ARCH-003A — provenance test must reach semantic projection identity/hash

**Verdict:** INCOMPLETE TEST ORACLE  
**Severity:** CRITICAL for closure

`test_provenance_carries_source_hash_and_changes_with_source` currently compares only canonicalized in-memory `provenance` lists between two fixtures.

The governed requirement is stronger: a provenance-only correction must be observable in the canonical logical projection output **and its semantic projection identity/hash/diff surface**, while unchanged fact values remain unchanged.

Add a test that changes only source/provenance state and proves:
- canonical provenance output changes;
- projection/provenance output hash changes;
- final `projection_hash` changes if that hash is defined as semantic identity of all canonical logical outputs;
- fact/value output remains semantically unchanged where appropriate.

Without that, implementation could pass this test while still reproducing the original AUD-ARCH-003 defect at the manifest/hash level.

---

### AUD-ARCH-002C — ENTITY_LINK fixture freezes an untyped target prematurely

**Verdict:** CONFLICT WITH CURRENT SCHEMA-CONTRACT FRONTIER  
**Severity:** HIGH

The test helper encodes entity-link target as naked `value: "global:fixture"`.

Director issue #52 now explicitly requires typed subject references and leaves decision-type value semantics as a governed schema concern. An ENTITY_LINK needs a deterministic typed/versioned target representation before its application behavior should become a frozen regression oracle.

Do not turn an arbitrary string global ID into de facto schema merely because it is convenient in the first compiler test.

---

### AUD-ARCH-002D — current test set covers only one reconciliation decision type

**Verdict:** INCOMPLETE FOR FULL AUD-ARCH-002 CLOSURE  
**Severity:** HIGH

Current tests exercise ENTITY_LINK and its supersession only.

Full deterministic reconciliation application also needs governed behavior for at least:
- `ASSERTION_STATUS`;
- `SCOPE_RESOLUTION`;
- supersession/currentness across decision types;
- explicit unresolved/contested behavior when decisions conflict or are absent.

The tranche may remain bounded to ENTITY_LINK, but its eventual green status must be reported as partial AUD-ARCH-002 closure, not full reconciliation closure.

---

### Fail-closed missing projection status

**Verdict:** SUPPORTED

Mapping an accepted assertion with absent projection status into explicit `UNRESOLVED` rather than silently `STABLE` is directionally consistent with the Project's fail-closed method, provided:
- worker assertion bytes are preserved;
- evidence/provenance remain linked;
- the unresolved reason is deterministic and queryable;
- later accepted reconciliation can supersede/promote without rewriting history.
