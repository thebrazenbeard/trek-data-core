# Research partitions

Workers write only inside their assigned partition. Declared top-level lanes are `tos`, `tas`, `tng`, `ds9`, `voyager`, `enterprise`, `discovery`, `short-treks`, `picard`, `lower-decks`, `prodigy`, `strange-new-worlds`, `starfleet-academy`, `films`, and `literature`.

Each bounded batch contains a manifest plus only the local evidence/assertion/entity records produced by that batch. Shared global identities are resolved later.

Coverage is not a single counter. Source binding/full-text availability, structural indexing, close-read/semantic analysis, entity-link/cross-reference, and audit states are tracked independently using governed coverage-state records and medium-specific denominators.
