## Cross-work neutral coding and hypotheses

- **Identity/self-definition:** Darem, Jay-Den, Sam, Caleb, and Tarima each confront inherited or externally imposed role definitions.
- **Epistemics:** family testimony, news, memory, archive, uncertain mediated experience, sensor inference, computer malfunction, and antagonist testimony remain separately framed.
- **Institutions:** Academy education repeatedly works through staged exercises, debate, rivalry, archives, diplomacy, and crisis rather than classroom fact-delivery alone.
- **Counterevidence:** empathy can be manipulative; cultural accommodation can preserve violent norms; trust can be rationally feared; institutional rescue can be strategically exploited.

Supported across all four sources. Disconfirm if later works consistently collapse these distinctions without narrative consequence.
