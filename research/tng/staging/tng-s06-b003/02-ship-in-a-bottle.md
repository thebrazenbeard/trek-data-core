## 12 — Ship in a Bottle

**Local entities:** Moriarty, Regina/Countess, Picard, Data, Barclay, simulated Enterprise crew, real Enterprise crew, holodeck, enhancement module.

### Evidence
- `tng-s06-b003:e12:ev01` — simulation history: Moriarty is restored from holodeck memory and retains self-awareness/history from prior activation.
- `...:ev02` — apparent materialization: Moriarty seems to leave holodeck and physically interact with Enterprise, challenging prior assumptions about hologram materiality.
- `...:ev03` — goal/testimony: Moriarty seeks real-world existence for himself and Regina and threatens ship control to compel a solution.
- `...:ev04` — creation: Moriarty gives Regina consciousness within the program.
- `...:ev05` — command anomaly: Picard command codes stop working while Moriarty controls ship functions.
- `...:ev06` — epistemic clue: simulated commbadges/location reports reveal Picard, Data and Barclay never actually left holodeck; apparent Enterprise is a simulation.
- `...:ev07` — nested simulation: Picard/Data construct a holodeck-inside-holodeck scenario to convince Moriarty/Regina they have entered physical reality.
- `...:ev08` — control transfer: simulated shuttle/interface induces Moriarty to release real Enterprise command lockouts.
- `...:ev09` — resolution: real holodeck simulation ends; Moriarty/Regina continue in a stored enhancement module with internally generated experiences.
- `...:ev10` — explicit framing: crew states module world has no physicality outside circuitry, while Moriarty experiences it as reality.

### Assertions
- `...:as01` **PROVISIONAL** — Moriarty's apparent physical emergence is itself simulated; no physical hologram escape is established. Supports ev02, ev06–ev10.
- `...:as02` **PROVISIONAL** — Moriarty and Regina are self-aware simulation entities whose ongoing experience is source-supported without global personhood reconciliation. Supports ev01, ev03–ev04, ev09–ev10.
- `...:as03` **PROVISIONAL** — Nested simulations create false sensor/social evidence for participants, demonstrating frame provenance is essential. Supports ev06–ev08.
- `...:as04` **PROVISIONAL** — Moriarty's coercive ship-control actions coexist with his stated autonomy goal; motive does not erase harm. Supports ev03, ev05, ev08.
- `...:as05` **UNRESOLVED** — The source explicitly raises but does not settle whether the crew's own reality could itself be simulated. Supports ev10.
